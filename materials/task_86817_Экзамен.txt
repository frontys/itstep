Вот 5 комплексных экзаменационных заданий по JavaScript. Все задания рассчитаны на реализацию в формате:
HTML + CSS + JavaScript
данные хранить в localStorage в формате JSON.

Задание 1. Система регистрации на курс
Создать мини-сайт регистрации учеников на IT-курс.
Пользователь вводит:
имя;
email;
возраст;
выбранный курс;
пароль.
Реализовать:
регистрацию пользователя;
проверку, чтобы email не повторялся;
авторизацию по email и паролю;
вывод личного кабинета после входа;
кнопку выхода;
сохранение пользователей в localStorage.


Задание 2. Электронный журнал группы
Создать приложение для учёта оценок студентов.
Данные студента:
имя;
группа;
предмет;
массив оценок.
Реализовать:
добавление студента;
вывод всех студентов;
подсчёт среднего балла каждого студента;
поиск студента по имени;
вывод студентов со средним баллом ниже 6;
сохранение данных в localStorage.


Задание 3. Мини CRM для заявок
Создать систему обработки заявок клиентов.
Данные заявки:
имя клиента;
телефон;
услуга;
статус: новая, в работе, закрыта;
дата создания.
Реализовать:
добавление заявки;
вывод всех заявок;
фильтр по статусу;
изменение статуса заявки;
удаление заявки;
сохранение заявок в localStorage.


Задание 4. Склад компьютерной техники
Создать приложение складского учёта.
Данные товара:
название;
категория;
цена;
количество;
минимальный остаток.
Реализовать:
добавление товара;
вывод всех товаров;
подсчёт общей стоимости склада;
поиск товара по названию;
вывод товаров, которых мало на складе;
удаление товара;
сохранение товаров в localStorage.


Задание 5. Система онлайн-тестирования
Создать приложение для прохождения теста по JavaScript. (минимум 20 вопросов)
Данные вопроса:
текст вопроса;
4 варианта ответа;
номер правильного ответа.
Реализовать:
вывод всех вопросов;
выбор ответа пользователем;
подсчёт правильных ответов;
вывод результата в процентах;
сохранение последнего результата в localStorage;
вывод предыдущего результата при повторном открытии страницы.
