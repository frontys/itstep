1. Каталог ноутбуков
Создать массив объектов с ноутбуками.
У каждого ноутбука:
модель;
процессор;
оперативная память;
цена.
Вывести все ноутбуки и найти самый дорогой.

2. Учёт посетителей спортзала
Создать массив объектов с посетителями.
У каждого посетителя:
имя;
возраст;
тип абонемента;
количество посещений.
Найти посетителя с наибольшим количеством посещений.

3. Заказы в интернет-магазине
Создать массив объектов заказов.
У каждого заказа:
номер заказа;
имя клиента;
сумма заказа;
статус.
Вывести только заказы со статусом "доставлен".

4. Склад продуктов
Создать массив объектов продуктов.
У каждого продукта:
название;
цена;
количество на складе.
Посчитать общую стоимость всех продуктов на складе.

5. Список фильмов
Создать массив объектов фильмов.
У каждого фильма:
название;
жанр;
год выпуска;
рейтинг.
Вывести фильмы с рейтингом выше 8.

6. Журнал температуры
Создать массив температур за неделю.
Нужно:
вывести все температуры;
найти самую высокую;
найти самую низкую;
посчитать среднюю температуру.

7. Расходы за месяц
Создать массив расходов.
Каждый расход — объект:
категория;
сумма;
день месяца.
Посчитать общую сумму расходов и вывести расходы больше 1000.

8. Расписание занятий
Создать многомерный массив, где каждая строка — отдельный день недели.
Например:

[
	["Математика", "Физика"],
	["JavaScript", "Английский"],
	["История", "Физкультура"]
]
Вывести расписание по дням.

9. Таблица продаж
Создать многомерный массив продаж по магазинам.
Каждая строка — магазин.
Каждый элемент строки — продажи за день.
Найти сумму продаж каждого магазина.

10. Оценки учеников по предметам
Создать многомерный массив оценок.
Каждая строка — ученик.
Каждый столбец — оценка по предмету.
Посчитать среднюю оценку каждого ученика.

11. Матрица мест в кинотеатре
Создать многомерный массив мест.
Например:
[
	["свободно", "занято", "свободно"],
	["занято", "свободно", "свободно"]
]
Посчитать количество свободных мест.

12. Проверка email
Создать функцию, которая принимает email.
Функция должна проверить:
есть ли символ "@";
есть ли точка ".".
Если оба условия выполняются — вывести "Email похож на правильный", иначе — "Email некорректный".

13. Обработка имени пользователя
Создать функцию, которая принимает имя пользователя.
Функция должна:
вывести длину имени;
вывести имя в верхнем регистре;
вывести имя в нижнем регистре.


14. Поиск запрещённого слова
Создать строку с комментарием пользователя.
Создать функцию, которая проверяет, содержит ли комментарий запрещённое слово.
Если содержит — вывести "Комментарий заблокирован".
Иначе — "Комментарий опубликован".

15. Разделение списка товаров
Есть строка:
"хлеб, молоко, сыр, чай"
Разделить строку на массив товаров и вывести каждый товар отдельно.

16. Подсчёт слов в сообщении
Создать строку с сообщением пользователя.
С помощью split() разбить строку на слова.
Посчитать количество слов в сообщении.

20. Мини-отчёт по магазину

У каждого товара:
название;
категория;

Нужно:
вывести все товары;
