1. Карточка пользователя
Создать JSON-строку с данными пользователя:
имя;
возраст;
город;
email.
По нажатию на кнопку преобразовать JSON в объект и вывести данные пользователя на страницу.

2. Каталог товаров магазина
Создать JSON-массив товаров.
У каждого товара:
название;
категория;
цена;
наличие на складе.
Вывести на страницу только товары, которые есть в наличии.

3. Расчёт суммы заказа
Создать JSON-массив товаров в заказе.
У каждого товара:
название;
цена;
количество.
По нажатию на кнопку вывести список товаров и общую сумму заказа.

4. Фильтр учеников по оценке
Создать массив учеников в формате JSON.
У каждого ученика:
имя;
группа;
средний балл.
Пользователь вводит минимальный балл.
Вывести учеников, у которых средний балл выше введённого значения.

5. Поиск книги в библиотеке
Создать JSON-массив книг.
У каждой книги:
название;
автор;
год выпуска;
доступна ли книга.
Пользователь вводит название книги.
Программа должна найти книгу и вывести информацию о ней.

6. Сортировка ноутбуков по цене
Создать JSON-массив ноутбуков.
У каждого ноутбука:
модель;
процессор;
оперативная память;
цена.
По нажатию на кнопку отсортировать ноутбуки по цене от дешёвых к дорогим.

7. Список задач пользователя
Создать JSON-массив задач.
У каждой задачи:
текст задачи;
статус: done или active.
Сделать выпадающий список для выбора статуса.
Вывести задачи выбранного статуса.

8. Мини-журнал группы
Создать JSON-объект группы.
Внутри объекта должны быть:
название группы;
преподаватель;
массив студентов.
У каждого студента должен быть массив оценок.
Посчитать средний балл каждого студента.

9. Добавление клиента в CRM
Создать массив клиентов.
Через HTML-форму пользователь вводит:
имя клиента;
телефон;
сумму покупок.
После нажатия кнопки новый клиент добавляется в массив и выводится общий список клиентов.

10. VIP-клиенты магазина
На основе массива клиентов из задания 9 вывести только тех клиентов, у которых сумма покупок больше 10000.

11. Проверка JSON из textarea
На странице должно быть поле textarea.
Пользователь вставляет JSON-массив товаров.
После нажатия кнопки программа должна:
проверить правильность JSON;
если всё верно — вывести товары;
если есть ошибка — вывести сообщение Ошибка в JSON.

12. Сохранение заметок в localStorage
Пользователь вводит текст заметки.
После нажатия кнопки заметка сохраняется в localStorage в формате JSON.
На странице должна быть кнопка для вывода сохранённой заметки.

13. История расходов
Создать форму для добавления расхода:
категория;
сумма;
дата.
Каждый расход сохранять в массив объектов.
Вывести все расходы и общую сумму.

14. Онлайн-заказы кафе
Создать JSON-массив заказов кафе.
У каждого заказа:
номер заказа;
имя клиента;
список блюд;
статус заказа.
Реализовать фильтрацию заказов по статусу:
новый;
готовится;
выполнен.

15. Мини-система бронирования
Создать JSON-массив бронирований.
У каждого бронирования:
имя клиента;
дата;
время;
количество человек.
Через форму добавить новое бронирование и вывести список всех бронирований.
