1. Калькулятор стоимости доставки
На странице должны быть поля:
стоимость товара;
стоимость доставки.
По нажатию на кнопку вывести итоговую сумму заказа.


2. Расчёт площади комнаты
Пользователь вводит:
длину комнаты;
ширину комнаты.
Программа должна вывести площадь комнаты и текст:
Площадь комнаты: ... м²

3. Оплата за несколько занятий
Пользователь вводит:
стоимость одного занятия;
количество занятий.
Программа должна посчитать общую оплату за курс.

4. Проверка доступа на сайт
Пользователь вводит возраст.
Если возраст 16 или больше — вывести:
Регистрация разрешена
Иначе вывести:
Регистрация запрещена

5. Проверка температуры
Пользователь вводит температуру.
Вывести:
меньше 0 — Мороз;
от 0 до 20 — Прохладно;
больше 20 — Тепло.

6. Расчёт скидки в магазине
Пользователь вводит сумму покупки.
Если сумма больше 2000, применить скидку 15%.
Иначе скидка не применяется.
Вывести:
сумму покупки;
размер скидки;
итоговую сумму.


7. Проверка результата теста
Пользователь вводит количество баллов от 1 до 100.
Вывести:
90–100 — Отличный результат;
70–89 — Хороший результат;
50–69 — Тест сдан;
меньше 50 — Тест не сдан.


8. Генератор списка чисел
Пользователь вводит число N.
После нажатия кнопки программа должна вывести все числа от 1 до N.


9. Сумма платежей
Пользователь вводит число N.
Программа должна посчитать сумму чисел от 1 до N и вывести результат.


10. Таблица умножения для тренировки
Пользователь вводит число.
Программа должна вывести таблицу умножения этого числа от 1 до 10.


11. Чётные номера домов
Пользователь вводит максимальный номер дома.
Программа должна вывести все чётные номера домов от 1 до введённого числа.

12. Таймер обратного отсчёта
Пользователь вводит число.
Программа должна вывести обратный отсчёт от этого числа до 1 и в конце сообщение:
Время вышло!

13. Список товаров магазина
На странице есть кнопка Показать товары.
После нажатия вывести заранее созданный массив товаров на страницу.

14. Общая сумма расходов
Создать массив расходов за неделю.
По нажатию на кнопку вывести:
все расходы;
общую сумму расходов.


15. Самая большая зарплата
Создать массив зарплат сотрудников.
По нажатию на кнопку найти и вывести самую большую зарплату.

16. Средний балл группы
Создать массив оценок учеников.
По нажатию на кнопку вывести:
все оценки;
средний балл группы.


17. Поиск дорогих товаров
Создать массив цен товаров.
По нажатию на кнопку вывести только те цены, которые больше 1500.

18. Подсчёт отрицательных чисел
Создать массив чисел.
По нажатию на кнопку посчитать, сколько в массиве отрицательных чисел.

19. Поиск ученика в списке
На странице должно быть поле для ввода имени.
Есть заранее созданный массив учеников.
После нажатия кнопки программа должна проверить, есть ли такое имя в списке.

20. Мини-корзина интернет-магазина
Создать два массива:
названия товаров;
цены товаров.
По нажатию на кнопку вывести:
список товаров с ценами;
общую сумму корзины;
самый дорогой товар.
