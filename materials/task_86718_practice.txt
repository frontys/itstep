1. Система регистрации учеников на курс

Создать страницу регистрации на курс программирования.

Пользователь вводит:

имя;
email;
возраст;
выбранный курс;
пароль.

Данные сохраняются в localStorage в формате JSON.

Дополнительно:

нельзя зарегистрировать двух пользователей с одинаковым email;
при входе проверять email и пароль;
после входа показывать личный кабинет ученика.

15. Тест по JavaScript

Создать приложение для прохождения теста.

варианты ответов;
правильный ответ.

Функционал:

дать пользователю выбрать ответы;
посчитать количество правильных ответов;
сохранить последний результат теста в localStorage.
