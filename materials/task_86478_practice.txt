Задание 1. Случайный цвет
Создайте HTML-страницу с кнопкой и блоком div.
При нажатии на кнопку фон блока должен менять цвет на случайный.
Дополнительно выведите код цвета внутри блока.

Задание 2. Координаты курсора и двойной клик
Создайте HTML-страницу с большим блоком div.
При движении мышки внутри блока должны отображаться координаты курсора.
При двойном клике по блоку должно выводиться сообщение:
Вы сделали двойной клик.

Задание 3. Показать / скрыть изображение
Создайте HTML-страницу с кнопкой и изображением.
При нажатии на кнопку изображение должно скрываться.
При повторном нажатии изображение должно снова отображаться.
Текст кнопки должен меняться:
Скрыть изображение / Показать изображение.

Задание 4. Переключение карточек товаров
Создайте HTML-страницу с несколькими кнопками категорий:
Ноутбуки, Смартфоны, Планшеты.
При нажатии на категорию должна отображаться только карточка с товарами выбранной категории.
Одновременно должна быть видна только одна категория.

Задание 5. Список задач
Создайте HTML-страницу со списком задач.
Возле каждой задачи должна быть кнопка Выполнено.
При нажатии на кнопку задача должна перечёркиваться и менять цвет текста.
Повторное нажатие должно возвращать задачу в обычное состояние.
