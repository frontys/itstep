# HTML & CSS Projects Collection — ITStep Academy

A curated collection of responsive multi-page websites and interactive web interfaces built during courses at ITStep Academy.

---

## 📂 Projects Overview

| Project | Directory | Description | Stack |
| :--- | :--- | :--- | :--- |
| 📚 **Bookstore** | [`bookstore/`](./bookstore/) | Multi-page online bookshop: catalog with 14 detailed book cards, shopping cart, and contact form | HTML5, CSS3 |
| 🏋️ **Fitness Club** | [`fitness-club/`](./fitness-club/) | Modern fitness club landing: training programs, schedule, nutrition plans, and authentication forms | HTML5, CSS3 |
| 🏥 **Medical Clinic** | [`medical-clinic/`](./medical-clinic/) | Healthcare portal: doctor directory, appointment booking, login, and registration flows | HTML5, CSS3 |
| 🛍️ **E-Commerce Store** | [`ecommerce-shop/`](./ecommerce-shop/) | Responsive electronics shop showcase with product cards and cart view | HTML5, CSS3 |
| 📋 **CRM Request Manager** | [`crm-requests/`](./crm-requests/) | Single-page service request dashboard with status management and persistent storage | HTML5, CSS3, Vanilla JS, LocalStorage |

---

## 🛠️ Tech Stack

- **Markup:** Semantic HTML5
- **Styling:** Modern CSS3 (Flexbox, CSS Grid, media queries for responsive layouts)
- **Scripting:** Vanilla JavaScript (ES6+), Web Storage API (`localStorage`)

---

## 🚀 Getting Started

All projects are standalone static web pages and require no build tools:
1. Clone the repository:
   ```bash
   git clone https://github.com/frontys/html-css-projects.git
   ```
2. Open `index.html` inside any project folder in your favorite browser, or serve via the VS Code **Live Server** extension.
