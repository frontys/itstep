# GameCatalog

Board games catalog web application built with React and Vite.

## Features
- User registration and login with local data persistence
- Board games catalog with initial set of 10 items
- Search by game title or publisher
- Filtering by genre and player age
- Sorting by publisher, title, and price
- Add new game form with image support

## Getting Started
1. Install dependencies: `npm install`
2. Start dev server: `npm run dev`
3. Build production bundle: `npm run build`
